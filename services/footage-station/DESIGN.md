# Footage station visual system

A white workspace with dark neutral text and a restrained amber action color.
Primary hue is anchored to the generated OKLCH 77.1° seed; darker lightness keeps
button contrast readable. System sans-serif, 16px body, 28px page heading.

Use one station status band, a separated list of imports and an adjacent detail
panel. On phones these stack in reading order. Borders separate content; no
nested cards or decorative shadows. State labels accompany every color cue.
Controls are at least 44px tall. The import list retains selection during polling;
active form fields never get replaced by background refreshes.
