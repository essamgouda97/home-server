# Home server interfaces

## Register

product

## Users and purpose

The owner and household use clean LAN URLs to access self-hosted services.
The owner uses a private whiteboard for planning and architecture diagrams,
including live editing with Codex. Saved boards must survive service restarts.

## References and personality

Preserve existing Homarr and Excalidraw conventions. The requested reference is
Excalidraw+ for saved boards and easy return to ongoing projects. Keep the
interface familiar, practical, and quiet.

## Design principles

- Service names and links must explain what the household can do.
- Status indicators must describe real service reachability.
- Keep saving and recovery visible and reliable.
- Keep drawings and assets on the home server.
- Avoid cloud signups, subscription prompts, and developer diagnostics in normal use.

## Accessibility

Preserve native keyboard controls, visible focus, and readable labels.
Use existing application components and responsive layouts.
